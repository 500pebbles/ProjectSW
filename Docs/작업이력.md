## 카드 B. 데미지 + 칼날 판정 + 더미

- 근접 데미지: GE_Damage_Melee(Instant, Health Add, SetByCaller), SoulMeleeAbility::ApplyMeleeDamage가 −(AttackPower × 배율) 전달 (10/29 이전 때 팀 ExecCalc 흐름으로 교체)

- 칼날 판정: SoulAnimNotifyState_MeleeTrace(C++, Source/ProjectSW/Worker/Anim)

  - 노티파이는 상태를 저장하지 않음, ASC 없는 소유자(에디터 미리보기)는 건너뜀, 디버그 콘솔 SW.Debug.MeleeTrace 1

- GA_Attack: HitActors(Set)로 한 번 휘두를 때 대상당 1회, 배율 1.0 / 1.1 / 1.3 / 1.5 / 2.0
- 확인: 로코타운 PIE에서 타마다 배율 데미지, HP 0 사망 1회, 대상당 1회

## 카드 C. 입력 정책 + 5타 콤보 + 선입력
- 입력 정책(팀 입력 경로 수정): Pressed에서 1회 발동, 실행 중이면 입력만 전달, Held 반복 발동 제거
  - SoulAbilitySystemComponent: AbilityInputTagPressed, AbilitySpecInputPressed override(실행 중 GA에 InputPressed 이벤트, WaitInputPress 동작)
  - SoulPlayerController: AbilityInputTagPressed 구현
- 공격 중 이동: States.Attacking 중에는 이동 대신 입력 방향만 기록, 타 시작 때 그 방향으로 회전
- WorkerAttack_Montage: B_N_Attack_01~05, 섹션 Attack1~5(자동 연결 끊음)
- ANS_ComboWindow(입력 구간) + AN_ComboBranch(전환 시점), 1~4타
- 태그: Abilities.Attack, States.Attacking, Events.Combo.Open/Close/Branch
- 팀 영향: LMB 꾹 누름 연사 없음(GA_Fireball 포함)
- 확인: PIE 로그로 무시·예약·즉시 입력과 5타 정지

## 카드 D. 회피(대시) + 무적 + 공격 캔슬
- 입력: IA_WorkerDash(LeftShift) + InputTags.Dash, 팀 DA_SoulInputConfig 대신 사본 DA_WorkerInputConfig를 BP_WorkerPlayerController에 지정
- SoulPlayerController: 이동 입력 방향 저장 + GetMoveInputDirection
- GA_Dash: 입력 방향(없으면 정면)으로 회전 후 ApplyRootMotionConstantForce(1800, 0.25초), 이동이 끝나면 GA 종료, End 클립은 계속 재생되고 공격으로 끊김
  - 실행 중 States.Dashing·States.Invincible, Abilities.Attack 캔슬·차단
- GE_Damage_Melee: Must Not Have Tags에 States.Invincible
- 확인: 입력 방향 대시, 콤보 중 캔슬, 대시 후 1타부터, End 중 공격으로 끊김, 대시 0.25초 안 입력 무시
- 보류: 무적 차단 확인용 피격 테스트 BP, 대시 튜닝(End 중 이동 미끄러짐, 거리·속도)
